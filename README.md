# fruitbench

Teaching Moshi (`kyutai/moshiko-pytorch-bf16`) to play **fruit-bench**: the user and Moshi take turns
naming fruits as fast as possible. Training will use GRPO; this repo currently contains the
simulator, scorer and base-model evaluation.

Environment: reuses the `uv` environment of `/root/moshi-finetune`
(fork of kyutai moshi-finetune). Run scripts with `/root/moshi-finetune/.venv/bin/python`.

Decisions and reasons: `results/LOG.md`.
